# Responsive Sports E-Commerce Website

A modern and responsive **sports e-commerce website** built using **HTML5 and CSS3**.  
This project focuses on clean UI design, layout structure, and responsiveness without using JavaScript or external frameworks.

🔗 **Live Demo:**  
https://parinazvr.github.io/Responsive-Sports-E-Commerce-Website/

🔗 **Source Code:**  
https://github.com/Parinazvr/Responsive-Sports-E-Commerce-Website

---

## 📌 Features

- Responsive layout for desktop, tablet, and mobile screens
- Modern sports-themed UI design
- Clean and semantic HTML structure
- Custom CSS styling
- Static frontend implementation (no JavaScript)

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **Git & GitHub**
- **GitHub Pages** (for deployment)
